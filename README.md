
# PressureProbe

Evaluating Linux PSI for Diagnosing Application Latency Under
Controlled CPU, Memory, and I/O Contention.

## Objective

Investigate how reliably Linux Pressure Stall Information (PSI)
helps explain application latency under controlled resource contention.

## Core Components

- Linux PSI collection
- Application latency measurement
- Controlled CPU, memory, and I/O experiments
- Evidence-based diagnostic analysis
- Performance visualization and evaluation

## Environment

- Development: Windows and Python
- Experimental validation: Native Linux
